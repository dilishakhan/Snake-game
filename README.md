# Snake-game
Snake Game (Python Turtle):

A simple implementation of the classic Snake Game using Python’s built-in turtle graphics module. The game allows the player to control a snake, eat food, grow in length, and try to achieve the highest score without colliding with the walls or itself.

Features:

-Smooth snake movement using keyboard controls

-Random food generation on the screen

-Snake grows longer after eating food

-Collision detection with walls and the snake’s own body

-Real-time score and high score tracking

-Gradually increasing game speed for added difficulty

Technologies Used:

-Python

-Turtle module

-Time module

-Random module

How to Run:

Make sure Python (version 3 or above) is installed on your system.

Save the code in a file named snake_game.py.

Open a terminal or command prompt in the project folder.

Run the following command:
python snake_game.py

Controls:

Use the keyboard to control the snake:

Press W to move up

Press S to move down

Press A to move left

Press D to move right

Game Logic:

The snake starts at the center of the screen and remains stationary until a movement key is pressed. When the snake eats food, its length increases and the score goes up. The food respawns at a random location each time it is consumed.

If the snake collides with the boundary of the window or with its own body, the game resets. The current score is reset to zero, while the high score is retained for the session.
